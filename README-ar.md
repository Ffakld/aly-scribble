# علي — ALY Scribble

خط عربي وإنجليزي مرسوم من الصفر، بطابع قلم مستدير وتفاوت خفيف في سماكة الضربات. العائلة فيها وزن عادي ووزن عريض.

## الملفات

- ALYScribble-Regular.ttf وALYScribble-Bold.ttf: للاستخدام والتثبيت في البرامج والأجهزة التي تدعم خطوطًا مخصصة.
- OTF: صيغة بديلة للبرامج التي تفضلها. ثبّت صيغة واحدة لكل وزن لتجنب تكرار الاسم.
- WOFF2: للويب؛ ملف specimen.html يستخدمها محليًا.
- source/: الرسومات الأصلية، أداة البناء، قواعد OpenType، وملفات التحقق.
- OFL.txt: نص الرخصة المفتوحة الكامل.

## التغطية

يغطي الحروف العربية الأساسية والهمزات، أشكال الحروف حسب موقعها، التشكيل المعتاد: الفتحة والضمة والكسرة والشدة والسكون والتنوين والمدّة والهمزة والألف الخنجرية. يتضمن حرف التطويل «ـ»، لام ألف بأشكالها، وبعض الحروف الفارسية، والإنجليزية الكبيرة والصغيرة، وثلاث مجموعات أرقام 0123456789 و٠١٢٣٤٥٦٧٨٩ و۰۱۲۳۴۵۶۷۸۹، وعلامات الترقيم والرموز الأكثر استخدامًا.

التغطية هي 398 رمز Unicode و350 شكل حرف. ليس خطًا لكل Unicode أو للإيموجي أو لضبط المصحف؛ علامات التجويد المتخصصة ليست ضمن هذا الإصدار. برنامج العرض يستطيع استخدام خط آخر للرموز غير الموجودة.

## التشكيل والتطويل

اكتب التشكيل من لوحة المفاتيح العربية كما تكتب عادة. أمثلة: عَلِيٌّ، لَقْطَةٌ، قَهْوَةٌ، مُصَوِّرٌ.

التمديد بحرف U+0640 «ـ»: علي → عـلـي → عــــلــــي. تستطيع نسخ الحرف وتكراره. يتمدد بين الحروف القابلة للوصل؛ الحروف مثل ا ود ور لا تتصل بالحرف التالي من جهة اليسار، وهذا سلوك العربية الصحيح. مدّة الألف «آ» مختلفة عن التطويل.

## الاستخدام

على Windows: افتح ملف TTF واختر تثبيت. على macOS: افتحه في Font Book. الخط غير مثبت تلقائيًا.

على الجوال: احفظ ملف TTF في تطبيق الملفات، ثم استورده داخل تطبيق التصميم أو المستندات الذي يدعم استيراد الخطوط. على iPhone وiPad، تثبيت الخطوط واستخدامها يعتمد على تطبيقات داعمة؛ يمكنك إدارة الخطوط المثبتة من الإعدادات > عام > الخطوط. لا يغيّر هذا تلقائيًا خط النظام أو النص العادي في بايو الحسابات. على Android، دعم خط محلي أو تغيير خط النظام يختلف حسب الجهاز والتطبيق. استخدم الاستيراد داخل التطبيق إن كان متاحًا.

مرجع Apple: https://support.apple.com/en-gb/guide/iphone/iphb2517689c/ios

هذا خط عرض بطابع يدوي، مناسب للعناوين وأغلفة المقاطع والتصاميم. يُفضّل حجم 24 بكسل أو أكبر للكتابة العربية، خصوصًا مع التشكيل. لون الخط تختاره من التطبيق؛ ألوان المعاينة #263E31 و#D8C6A7 و#73543C.

## إعادة البناء

مع Python 3.12 أو إصدار متوافق:

    cd source
    python -m pip install -r requirements.txt
    python build_font.py
    python validate_font.py ../ALYScribble-Regular.ttf ../qa-Regular.json
    python validate_font.py ../ALYScribble-Bold.ttf ../qa-Bold.json

تُكتب ملفات الخط في مجلد الحزمة الأب. أداة البناء تستخدم إحداثيات الرسومات الأصلية وتحوّل الضربات إلى خطوط خارجية، ثم تجمع جداول الوصل والتشكيل ولام ألف والمسافات. يتطلب إنشاء WOFF2 مكتبة brotli.

## التحقق

تقارير QA المرفقة تفحص الحروف والتغطية وصحة الملف وأشكال العربي والسلوك مع التشكيل والتطويل واللام ألف ووصلات الحبر. تم فحص أشكال الحروف بصريًا ومعاينة الخط في محرّك تشكيل. نطاق التوافق النهائي يعتمد على البرنامج والجهاز؛ لا يصح ضمان خلو كل استخدام على كل جهاز من أي مشكلة.
